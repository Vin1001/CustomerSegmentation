# 🛒 E-Commerce Customer Segmentation Dashboard

A Machine Learning project developed using **Python**, **Streamlit**, **Scikit-Learn**, **Pandas**, and **Plotly** for customer segmentation using the K-Means clustering algorithm.

---

# Features

- Upload customer dataset (.csv)
- Automatic data validation
- Data cleaning
- Missing value handling
- Duplicate removal
- Feature preprocessing
- Feature scaling
- Exploratory Data Analysis (EDA)
- Correlation Heatmap
- Distribution Plots
- Boxplots
- Customer Overview Dashboard
- Elbow Method
- Silhouette Analysis
- K-Means Clustering
- PCA 2D Visualization
- PCA 3D Visualization
- Income vs Spending Dashboard
- Cluster Profiling
- Business Insights
- Business Recommendations
- TXT Report Generation
- PDF Report Generation
- CSV Export

# Installation

Clone the repository

```bash
git clone https://github.com/yourusername/E-Commerce-Customer-Segmentation.git
```

Move into the project directory

```bash
cd E-Commerce-Customer-Segmentation
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```
